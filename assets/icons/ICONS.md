# Skill icon assets

All icons are self-hosted; there are no browser-time icon/CDN requests.

- Existing brand assets were retained from the previous portfolio build.
- HTML5, CSS3, JavaScript, GitHub and Jest additions: Devicon SVGs, https://github.com/devicons/devicon (MIT; brand marks belong to their respective owners).
- Claude and GitHub Copilot additions: Simple Icons SVGs, https://github.com/simple-icons/simple-icons (CC0 project; brand usage restrictions/trademarks may apply).
- bcrypt, REST APIs, Supertest and PDFKit: original simple lock/API/check/document pictograms created for this portfolio, not represented as official product logos.
- Next.js App Router uses the Next.js mark with an explicit App Router label.

Icons indicate tools discussed in the portfolio, not sponsorship or endorsement. Learning/practice tools remain explicitly labelled as such when selected.
